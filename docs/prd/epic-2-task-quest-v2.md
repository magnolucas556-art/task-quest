# Epic 2 — Task Quest V2

## Objetivo

Evoluir a aplicação estática aprovada para incluir planejamento temporal, prioridade, calendário, visão analítica e uma experiência visual moderna, preservando dados e regras da V1.

## Sequência obrigatória

1. Story 2.1 — Redesign visual e tema claro/escuro.
2. Story 2.2 — Prioridade, prazos e migração V1→V2.
3. Story 2.3 — Calendário mensal.
4. Story 2.4 — Métricas, gráficos, animações e conclusão.

## Restrições

- HTML5, CSS3, JavaScript puro e LocalStorage.
- Sem backend, autenticação, API externa, framework ou bundler.
- Deploy estático e regras de XP preservados.
- Métricas e calendário derivados, nunca persistidos.
- Trabalho exclusivo na branch `feature/task-quest-v2` até autorização de merge/push.

## Definition of Done

- [ ] Stories 2.1–2.4 implementadas e revisáveis.
- [ ] Dados V1 migrados sem perda.
- [ ] 14 critérios de aceite V2 rastreados.
- [ ] Fluxos V1 sem regressão.
- [ ] Responsividade e acessibilidade básica validadas.
- [ ] Todos os quality gates aprovados.
- [ ] Commits locais claros, sem merge ou push.
